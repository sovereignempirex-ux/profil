04 / Inside the build

One gateway. Every client.

Every subsystem of the Vanitas platform — designed, built, tested and shipped end-to-end.

Identity & Auth

OAuth 2.0 across Google, GitHub, Discord, Microsoft, GitLab, LinkedIn and Twitch, plus email/password, TOTP 2FA — and Vanitas itself as an identity provider so third-party apps can "Sign in with Vanitas".

OAuth 2.0TOTPOIDCSessions

Security Core

Server-side RBAC, per-key scope validation, rate limiting at IP / user / key / endpoint levels, input sanitisation, XSS & CSRF protections, HttpOnly cookies and CSP/HSTS headers.

RBACScopesRate limitsAudit log

AI Suite

Assistants for code, API, documentation, security and analytics, plus web search and an Image Studio — powered by a Python FastAPI microservice with a TypeScript fallback and a local-first provider chain.

FastAPIOllamaFallbacks

Multi-platform Clients

Kotlin (Android), Swift (iOS) and C#/WPF (Windows) — each with its own offline test suite, all talking to the same authenticated gateway.

KotlinSwiftC# WPFReact

On-chain Credit

VanitasCredit — a Solidity off-chain ledger authorised with EIP-712 signatures. Any relayer can submit, so users pay no gas. 35 Forge tests, zero external dependencies.

SolidityEIP-712Foundry

Platform Services

A Go sliding-window rate limiter shared across gateway instances, a Python/R analytics service with anomaly detection, PostgreSQL with idempotent schema migrations — or a zero-config in-memory mode.

GoPython / RPostgreSQLDocker
